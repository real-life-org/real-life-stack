# Vom Ganzen zum Detail

**App → Instanz → App Shell → Space → Modul → Item-Vorschau → Detailansicht**

Starte bei **App / Gemeinschaftsgarten**. Wechsle Module, öffne das Erntefest und bearbeite den Titel. Alle Darstellungen beobachten dieselbe Datenquelle. Unter **App Shell** findest du die äußere Navigation, unter **Module** ganze Arbeitsflächen, unter **Items** deren gemeinsame Inhalte.

Die Begriffe des Stack mit ihren Verknüpfungen zu Netzwerk und Trust Protocol: [real-life.org/rls/v1](https://real-life.org/rls/v1/).
