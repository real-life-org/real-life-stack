# The space is the current working context

On the left in the community garden you switch to the open workshop. The app loads the new stock and clears its previous selection. Modules, detail host and frame stay the same building blocks — only the context changes.

<Canvas of={Garden.Garden} />

A space is not an instance: several spaces are reachable in the same running app. In the data model a **group** describes membership; a **space** is the configured working context of a group — its modules, its look, its members. The overview "Mein Netzwerk" aggregates across all spaces you belong to.

What a space decides: which modules it carries (`data.modules`), how it looks, who is in it. What it does not decide: how a module works — that is the same in every space.
